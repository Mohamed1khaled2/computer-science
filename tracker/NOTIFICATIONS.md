# الإشعارات في مسار مادا

كل الإشعارات اللي ممكن توصلك: إمتى بتيجي، مكتوب فيها إيه، وبتعمل إيه لما تدوس عليها.
النصوص هنا هي نفس اللي في الكود (`app/api/remind/fire/route.ts`).

> **على الآيفون:** مفيش أزرار في الإشعار. الضغط على الإشعار نفسه هو اللي بيعمل الحاجة المهمة،
> وفيه **رقم أحمر** بيظهر على أيقونة التطبيق ويختفي أول ما تفتحه.

---

## 1. المحاضرة بدأت 📚

| | |
|---|---|
| **إمتى** | في معاد كل محاضرة في جدولك (صفحة «الجدول والحضور») |
| **العنوان** | `📚 محاضرة الخميس 9:00 م بدأت` |
| **النص** | اسم الدرس اللي عليه الدور ← «ابدأ 10 دقايق بس وهتتحسب حضور.» ← «حضورك الأسبوع ده: 3/4» |
| **لما تدوس عليه** | بيفتح التطبيق على كارت «ابدأ 10 دقايق» |
| **الرقم الأحمر** | بيظهر (1) |
| **أزرار (Android/كمبيوتر بس)** | «ابدأ 10 دقايق» (التايمر بيشتغل على طول) · «تعبان» (وضع التعب) |
| **مش بيجي لو** | بدأت جلسة من ساعتين قبل المحاضرة أو أكتر وسجّلتها |

## 2. تسجيل الحضور ✓ (بعد المحاضرة بـ 3 ساعات)

| | |
|---|---|
| **إمتى** | بعد معاد المحاضرة بـ 3 ساعات، لو فيه جلسة بدأت في الفترة من ساعتين قبلها لحد 3 ساعات بعدها |
| **العنوان** | `✓ اتسجّل حضورك` — أو `✓ اتسجّل حضورك (متأخر شوية)` لو بدأت بعد المعاد بأكتر من 30 دقيقة |
| **النص** | «حضورك الأسبوع ده: 4/4» ← «المحاضرة الجاية: الجمعة 10:00 ص» |
| **لما تدوس عليه** | بيفتح كشف الحضور |
| **الرقم الأحمر** | بيتمسح |
| **أزرار** | «كشف الحضور» |

## 3. تسجيل الغياب ✗ (بعد المحاضرة بـ 3 ساعات)

**أول غياب:**

| | |
|---|---|
| **العنوان** | `✗ اتسجّلت غياب` |
| **النص** | «عادي، مرة واحدة. القاعدة: متغيبش مرتين ورا بعض.» ← حضورك الأسبوع ده ← المحاضرة الجاية |

**غياب مرتين أو أكتر ورا بعض:**

| | |
|---|---|
| **العنوان** | `✗ غياب 2 محاضرات ورا بعض` |
| **النص** | «ده بالظبط المكان اللي كنت بتقف فيه قبل كده. المحاضرة الجاية 10 دقايق بس — المهم ترجع.» ← حضورك الأسبوع ده ← المحاضرة الجاية |

**في الحالتين:**

| | |
|---|---|
| **لما تدوس عليه** | بيفتح التطبيق على كارت «ابدأ 10 دقايق» |
| **الرقم الأحمر** | بيظهر (1) |
| **أزرار** | «ابدأ 10 دقايق دلوقتي» · «كان عندي عذر» (بيفتح كشف الحضور) |
| **مش بيجي لو** | علّمت المحاضرة دي «بعذر» قبلها |

## 4. معادك دلوقتي ⏰ (الوعد)

| | |
|---|---|
| **إمتى** | في المعاد اللي بتحدده في آخر كل جلسة («هترجع إمتى؟») |
| **العنوان** | `معادك دلوقتي يا مادا ⏰` |
| **النص** | اسم الدرس ← «20 دقيقة بس. افتح وابدأ التايمر.» |
| **لما تدوس عليه** | كارت «ابدأ 10 دقايق» |
| **الرقم الأحمر** | بيظهر (1) |
| **أزرار** | «ابدأ 10 دقايق» |
| **مش بيجي لو** | غيّرت المعاد بمعاد تاني، أو ذاكرت من ساعتين قبله |

## 5. وعدت ترجع ولسه مجتش (بعد المعاد بساعة ونص)

| | |
|---|---|
| **العنوان** | `وعدت ترجع ولسه مجتش` |
| **النص** | «كان معادك 9:00 م. لسه فيه وقت — جلسة 20 دقيقة تنقذ اليوم.» |
| **الباقي** | زي إشعار رقم 4 |

## 6. إشعار التجربة

من الإعدادات ← الإشعارات ← «جرّب»:
`الإشعارات شغالة ✓` — «كده هيجيلك إشعار في معاد كل محاضرة، وبعدها تسجيل الحضور أو الغياب.»

## عدد الإشعارات في اليوم

- **يوم فيه محاضرة:** إشعارين: «المحاضرة بدأت» وبعدها الحضور أو الغياب. لو بدأت قبل المحاضرة، مش هيجيلك غير إشعار الحضور.
- **لو حددت معاد في آخر الجلسة:** إشعار في المعاد، وإشعار كمان بعده بساعة ونص لو ما جتش.
- **يوم إجازة من غير معاد:** مفيش إشعارات.

## مهم: السيرفر بيعرف إنك ذاكرت إزاي؟

من **الجلسات المتسجلة** بس، وبعد ما تتزامن. يعني:
- لازم **تسجّل الجلسة** في آخرها (التايمر لوحده مش كفاية).
- لازم **المزامنة تبقى شغالة** (نقطة خضرا جنب «متزامن»).
- لو ذاكرت ونسيت تسجّل: هيجيلك إشعار غياب، بس أول ما تسجّل الجلسة الكشف بيتصلّح لوحده.

## تشغيل الإشعارات على الآيفون

محتاج iOS 16.4 أو أحدث.

1. افتح التطبيق في **Safari**.
2. دوس زرار المشاركة ⬆️ ← **Add to Home Screen**.
3. افتح «مسار مادا» **من الأيقونة الجديدة**، مش من Safari.
4. الإعدادات ← احفظ الـ `SYNC_KEY` ← «فعّل الإشعارات هنا» ← **Allow**.
5. دوس «جرّب» واتأكد إن الإشعار وصل.
6. صفحة «الجدول والحضور» ← احفظ جدولك (عشان مواعيد المحاضرات تتسجّل على السيرفر).

## المطلوب على السيرفر (Vercel)

| المتغير | ليه |
|---|---|
| `SYNC_KEY` | حماية كل الـ API + المزامنة |
| `UPSTASH_REDIS_REST_URL` / `UPSTASH_REDIS_REST_TOKEN` | السيرفر بيقرا جلساتك منها عشان يعرف حضرت ولا لأ |
| `VAPID_PUBLIC_KEY` / `VAPID_PRIVATE_KEY` | إرسال الإشعارات (`npx web-push generate-vapid-keys`) |
| `QSTASH_TOKEN` | جدولة الإشعارات في مواعيدها |
| `APP_URL` | لينك التطبيق على Vercel (QStash بيناديه) |

الإشعارات مش بتشتغل من `localhost`، لأن QStash محتاج لينك حقيقي على الإنترنت.
